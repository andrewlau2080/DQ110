# DQ110 双速直流马达驱动器 · 使用说明书

产品型号：DQ110-V1.0  |  版本：V1.0  |  日期：2026-08-30

配套文件：《DQ110_产品规格书.md》（技术规格）、《DQ110_开发计划书.md》、《DQ110_FW_GITHUB》（固件源码）

## 1. 产品概述

DQ110 是一款电池供电的双速直流减速马达驱动器。通过三档船型开关控制马达的启停与转速：

| 开关位置 | 马达状态 | 驱动器行为 |
|---|---|---|
| 0 档 | 马达停止 | 进入待机（电流 ≤ 5µA） |
| 一档 | 15 RPM | 自动稳速 |
| 二档 | 30 RPM | 自动稳速 |

驱动器分两种版本（固件选项可选）：

| 版本 | 转速控制 | 说明 |
|---|---|---|
| 标准版（带霍尔） | 霍尔闭环 PID 稳速，精度 ±5% | 默认 |
| 低成本版（无霍尔，可选） | 开环线性调速 + 电压补偿恒速 | 省霍尔传感器，满电 15/30 RPM，电压下降自动加大 PWM 保持恒速；详见 4.6 |

两种版本均内置过流保护、看门狗与待机省电；标准版另有霍尔堵转检测，低成本版由过流保护承担堵转防护。

## 2. 产品组成与接口

### 2.1 外接端子

| 端子 | 名称 | 说明 |
|---|---|---|
| BAT+ | 电池正极 | 接 2 节 1 号电池正极（2.4V~3.2V） |
| BAT- | 电池负极 / 地 | 接电池负极，兼系统接地 |
| M+ | 马达正极 | 与电池正极直连（常通） |
| M- | 马达负极 | 驱动器功率输出，经内部 MOS 管 PWM 调速 |
| HALL | 霍尔信号 | 马达转速反馈信号输入 |
| SW1 | 一档检测 | 船型开关一档触点 |
| SW2 | 二档检测 | 船型开关二档触点 |

### 2.2 开关操作

| 开关位置 | 接线状态 | 驱动器行为 |
|---|---|---|
| 0 档 | SW1/SW2 均悬空 | 马达停止，进入待机 |
| 一档 | SW1 接通 BAT- | 马达 15 RPM 恒速 |
| 二档 | SW2 接通 BAT- | 马达 30 RPM 恒速 |

## 3. 使用方法

1. 安装电池：将 2 节 1 号电池按极性装入电池仓，确保 BAT+/BAT- 接线正确。
2. 连接马达：M+ 接马达正极，M- 接马达负极，霍尔线接 HALL（极性按马达霍尔接线定义）。
3. 拨动开关：
   - 拨到"一档"或"二档"：马达启动，自动调速到目标转速并保持稳定。
   - 拨回"0 档"：马达停止，驱动器进入待机省电模式。
4. 换挡：运行中可直接拨动开关切换档位，转速自动过渡到新目标。
5. 上电即用：若上电时开关已在档位上，驱动器会自动识别并启动马达，无需重新拨动。

## 4. 功能说明

### 4.1 转速闭环稳速（标准版，带霍尔）

驱动器通过霍尔传感器实时测量马达转速，由内部 PID 算法自动调节输出功率：

| 档位 | 目标转速 | 精度 |
|---|---|---|
| 一档 | 15 RPM | ±5% |
| 二档 | 30 RPM | ±5% |

负载变化（如阻力增大）时，驱动器自动补偿，转速基本不变。

### 4.2 过流保护

| 档位 | 保护阈值 | 响应时间 |
|---|---|---|
| 一档 | 0.65A | ≤ 100ms |
| 二档 | 1.3A | ≤ 100ms |

马达堵转、负载短路等导致电流超过阈值时，驱动器自动关断输出，防止烧毁马达与驱动电路。

### 4.3 堵转保护（标准版）

运行中若马达被卡死（500ms 内收不到转速信号），驱动器自动关断输出。启动瞬间的 1 秒内不判定堵转，避免误保护。

### 4.4 看门狗

驱动器内置独立看门狗，程序异常跑飞时自动复位重启，保证长期运行可靠。

### 4.5 待机省电

0 档时驱动器进入低功耗待机模式，待机电流 ≤ 5µA，2 节 1 号电池可用数年。

### 4.6 低成本版（无霍尔，可选）

低成本版不装霍尔传感器，采用**开环线性调速 + 电压前馈补偿恒速**：

| 项目 | 说明 |
|---|---|
| 满电转速 | 一档 15 RPM / 二档 30 RPM（3.0V 标定） |
| 恒速方式 | 电池电压下降时自动加大 PWM 占空比（线性补偿），转速保持基本恒定 |
| 堵转防护 | 由过流保护承担（堵转电流大 → 0.65A/1.3A 分级保护触发） |
| 低压保护 | 电池电压低于 2.0V（2 节碱性电池 1.0V/节标准截止）自动关断，防止过放 |
| 转速精度 | 开环补偿，随马达个体差异略有偏差，精度低于标准版 ±5% |

- 使用方式与标准版完全相同：三档开关、待机省电、回 0 档清除保护。
- 低压保护触发后更换电池，拨回 0 档即可恢复使用。

## 5. 保护触发与恢复

```
正常运行 ──过流/堵转──▶ 保护关断（停止输出）
    ▲                        │
    └────── 拨回 0 档 ────────┘
```

- 保护触发后，马达立即停止；此时拨动开关不会启动马达。
- **恢复方法：先将开关拨回 0 档（清除保护），再拨到需要的档位，驱动器恢复正常运行。**

### 5.1 常见问题排查

| 现象 | 可能原因 | 处理方法 |
|---|---|---|
| 拨档后马达不转 | 档位接触不良 / 刚上电识别中 | 重新拨动开关确认拨到位；上电后约 30ms 完成识别 |
| 马达转一下就停 | 过流保护触发（负载过大/卡死/短路） | 检查负载与接线；拨回 0 档清除保护后重拨 |
| 运行中突然停转 | 堵转保护触发（标准版：卡死/霍尔无信号） | 检查马达与霍尔接线；拨回 0 档后重拨 |
| 电压低自动停转 | 低压保护触发（低成本版，电池电压 < 2.0V） | 更换电池；拨回 0 档后重新使用 |
| 转速随电压下降明显变慢 | 低成本版补偿到上限（电池接近耗尽） | 更换电池；电压低于 2.0V 会自动关断 |
| 转速不稳定 | 霍尔信号异常（标准版） | 检查霍尔接线与安装间隙；确认供电 2.4V~3.2V |
| 完全无反应 | 电池没电 / 接线错误 | 更换电池；核对 BAT+/BAT-、M+/M- 接线 |

## 7. 安全与注意事项

1. 供电电压不得超过 3.2V，避免接反电池极性。
2. 马达运行中严禁直接短接 M+/M-，以免触发过流保护或损坏驱动电路。
3. 霍尔信号线应远离马达功率线，避免干扰导致转速误判。
4. 保护触发后请先排除故障（卡死、短路、过载）再恢复运行，勿反复强制启动。
5. 长时间不使用请将开关置于 0 档，进入待机省电。
6. 更换电池或检修前，请先关闭开关，断开电源。
