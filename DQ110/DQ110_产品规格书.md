# DQ110 双速直流马达驱动器 · 产品规格书

产品型号：DQ110-V1.0  |  版本：V1.0  |  日期：2026-08-27

## 1. 产品概述
用于驱动直流减速马达，实现双档位调速及过流保护。适用于电池供电的小型电动工具/设备。

## 4. 功能规格
- 档位控制：三档船型开关（0 档关 / 一档慢 / 二档快）
- 马达驱动：单 N-MOS 低侧驱动（单向），PWM 调速
- PWM 调速：16 位定时器，频率可调（20kHz）
- 转速闭环（标准版）：霍尔传感器反馈 + PID 算法稳速，±5%
- 恒速控制（低成本版可选）：无霍尔，开环线性调速 + 电压前馈补偿（电池电压下降自动加大 PWM 保持恒速，满电 15/30 RPM）
- 过流保护：采样电阻 + 运放 + ADC 检测，软件保护（两种版本通用）
- 过载保护：堵转检测自动关断（标准版霍尔检测；低成本版由过流保护承担）
- 低压保护（低成本版可选）：电池电压 < 2.0V 自动关断，防止过放
- 看门狗：独立 IWDG，防程序跑飞

## 5. 主控芯片（PY32F002A）

32 位 ARM Cortex-M0+ · 24MHz · 20KB Flash / 3KB SRAM · 1.7V~5.5V · 12 位 ADC（最多 9 外部通道）· TIM1（16 位高级，4 通道+3 路互补输出）+ TIM16 · LPTIM · 2 路比较器 · -40°C~+85°C

封装选型：主设计 TSSOP20（PY32F002AF15P，18 个 IO）；低成本同步版 SOP8（PY32F002AL15S，6 个 IO，单 MOS 驱动，见 7.5）。两种封装均支持"低成本版（无霍尔）"选项（编译 -DDQ110_HALL=OFF），省去霍尔传感器与上拉电阻，转速控制改为电压补偿开环恒速。

## 6. 环境与可靠性
- 工作温度：-10°C ~ +60°C；存储温度：-20°C ~ +70°C
- ESD 防护：≥ ±4kV（HBM）

### 7.3 IO 电路设计规范（TSSOP20 版，画原理图时按此执行）

- SW1 / SW2：三档船型开关公共端接 BAT-，一档触点接 SW1、二档触点接 SW2。0 档 = 两脚悬空，靠内部上拉保持高电平。外部禁止加下拉电阻（会与内部上拉分压导致档位误判）；抗干扰可在各脚对地并 10nF~100nF 电容。
- HALL：板上拉 4.7kΩ 至 VDD，霍尔悬空时读高 = 无信号；走线远离马达功率回路，可加 10nF 对地滤波。
- M+ / M-：单 N-MOS 低侧驱动。M+ 直接接 BAT+（VCC）；M- 接 N-MOS 漏极，源极经采样电阻（默认 0.1Ω / 1W）到 GND，栅极接 MCU PWM 输出（串联 10Ω~100Ω 限流电阻 + 栅源 10kΩ~100kΩ 下拉防上电误导通）。续流二极管（肖特基，如 SS14）并在马达两端，阴极接 M+。PWM 频率由 TIM1 输出，0~100% 调速。
- 过流检测（板内模拟通道，无外部端子）：采样电阻 + 运放 → 12 位 ADC，一档阈值 0.65A / 二档 1.3A，软件分级滤波，保护响应 ≤ 100ms。
- 待机：0 档时 SW1/SW2 均高，MCU 判定无档位后进入 Stop 模式，待机电流 ≤ 5µA（上拉漏电已计入）。

### 7.5 SOP8 低成本版（PY32F002AL15S，单 MOS 驱动）

SOP8 引脚：1=VCC，2=PA4/PA10，3=PA3，4=PA14-SWC/PB3，5=PA13-SWD，6=PA2/PF2-NRST，7=PA1，8=GND。仅 6 个 IO。

单向单 MOS 驱动下功能需求仅 5 个信号（PWM、SW1、SW2、HALL、过流），SOP8 完全装下，且 SW1/SW2 保持独立双线检测、与 TSSOP20 版一致，NRST 复位也保留：

| 脚号 | 引脚名 | DQ110 功能 | 方向 | 配置说明 |
|---|---|---|---|---|
| 1 | VCC | 电源 | 电源 | 2.4~3.2V，100nF + 10µF 退耦 |
| 2 | PA4 / PA10 | HALL（标准版） | 输入 | 选 PA4：TIM1_CH1（AF13）输入捕获；外部上拉 4.7kΩ。低成本版（无霍尔）不接，该脚释放（输入下拉防漏电） |
| 3 | PA3 | SW1 | 输入 | 内部上拉，低有效 |
| 4 | PA14-SWC / PB3 | SW2 | 输入 | 选 PB3 功能：内部上拉，低有效；复位后默认 SWCLK（调试/返修烧录），运行释放为 GPIO |
| 5 | PA13-SWD | M- 驱动 | 输出 | TIM1_CH2（AF13）PWM → MOS 栅极；复位后默认 SWDIO（调试/返修烧录），运行释放 |
| 6 | PA2 / PF2-NRST | 复位 | 输入 | 保留 NRST；外部上拉 10kΩ + 100nF 对地 |
| 7 | PA1 | 过流检测 | 模拟输入 | ADC_IN1：采样电阻+运放输出，一档 0.65A / 二档 1.3A，软件分级滤波 |
| 8 | GND | 地 | 电源 | |

注：PA13/PA14 复位后默认 SWD，运行时释放为 PWM/SW2；断电重启即恢复 SWD，可随时返修烧录，无需改 option byte。M+ 同 TSSOP20 版接 BAT+，M- 经单 N-MOS 低侧驱动，续流二极管并在马达两端。

低成本版（可选，无霍尔）：不装霍尔传感器与 4.7kΩ 上拉电阻，PA4 释放。转速控制改为开环线性调速 + 电压前馈补偿恒速——满电 3.0V 标定 15/30 RPM，电池电压下降自动同比例加大 PWM 保持恒速；电池电压由内置 VREFINT 基准反推（不占额外引脚）；低压保护 < 2.0V 自动关断（2 节碱性电池 1.0V/节截止）；堵转防护由过流保护承担。端子功能与标准版一致，仅控制方式不同（固件编译 -DDQ110_HALL=OFF）。
