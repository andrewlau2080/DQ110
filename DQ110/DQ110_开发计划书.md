# DQ110 双速直流马达驱动器 · 开发计划书

项目名称：DQ110 双速直流马达驱动器开发项目  |  日期：2026-08-27

## 1. 项目目标
- 技术目标：一档 15RPM、二档 30RPM 转速稳定，过流保护可靠
- 交付目标：6 周内交付 5 片功能完好的 PCBA 样品及全套设计文档

## 2. 项目团队
| 角色 | 职责 |
|---|---|
| 项目经理 | 项目协调、进度管理、客户沟通 |
| 硬件工程师 | 原理图设计、PCB Layout、BOM |
| 软件工程师 | 驱动开发、PID 算法、保护逻辑 |
| 测试工程师 | 功能测试、性能验证 |

## 3. 开发阶段与里程碑（6 周）
| 阶段 | 周期 | 核心任务 | 交付物 |
|---|---|---|---|
| 需求确认 | 第 1 周 | 需求评审、方案确认 | 需求规格确认书 |
| 硬件设计 | 第 2-3 周 | 原理图、PCB Layout、评审 | 原理图、PCB、BOM |
| 软件设计 | 第 2-4 周 | 驱动、PID、保护逻辑 | 软件源代码 |
| PCBA 制造 | 第 3-4 周 | 打样、采购、焊接 | 10 片 PCBA 裸板 |
| 调试与验证 | 第 4-5 周 | 功能调试、性能测试、过流标定 | 测试报告 |
| 优化与交付 | 第 5-6 周 | Bug 修复、文档、交付 | 5 片样品 + 全套文档 |

## 4. 测试与验收标准
| 验收项 | 标准 |
|---|---|
| 功能完整性 | 档位切换、调速、保护全部正常工作 |
| 转速精度 | 一档 15RPM ±5%，二档 30RPM ±5%（带载） |
| 过流保护 | 一档 0.65A / 二档 1.3A 可靠保护 |
| 待机功耗 | ≤ 5 µA（万用表测量） |
| 电源适应性 | 2.4V~3.2V 功能正常、转速稳定 |
| 文档完整性 | 原理图、BOM、源代码、测试报告齐全 |

## 5. 风险分析与应对
| 风险 | 概率 | 影响 | 应对措施 |
|---|---|---|---|
| 马达参数与规格不符 | 中 | 高 | 提前获取马达样品实测 |
| 转速闭环效果不达标 | 中 | 中 | 预留 PID 调试接口、延长调试期 |
| 过流保护误触发 | 中 | 中 | 硬件滤波 + 软件多次平均分级保护 |
| 元器件交期延误 | 低 | 中 | 提前采购、备选替代型号 |
